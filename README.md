## English

**The exact seed algorithm behind [SchulteLab's Daily Challenge](https://schultelab.org/daily-challenge/)** — one UTC date → one deterministic Schulte grid, identical for every player on Earth.

**Why this is open source:** the daily challenge claims "everyone worldwide plays the same board." That claim should not require trusting us — it should be runnable. This repo is byte-for-byte the same logic as the site's production code (`challenge.ts` + `engine.ts`), with test vectors generated by the production engine. If this output ever disagrees with the website, the website is wrong.

### The algorithm (3 steps)

1. **Date → seed** (integer): `seed = YYYY×10000 + MM×100 + DD` in UTC. e.g. `2026-09-01 → 20260901`
2. **Seed → PRNG**: [mulberry32](https://en.wikipedia.org/wiki/Mulberry32) — tiny deterministic 32-bit PRNG
3. **PRNG → grid**: build the ordered target sequence (`1…N²` for numbers, `A–Z` for letters), then Fisher–Yates shuffle driven by the PRNG

Same date → same seed → same shuffle → same board. No server, no database, no timezone drift (UTC only).

### Usage

```js
import { dailySeed, generateGrid, encodeChallenge, decodeChallenge } from './src/index.js'

const seed = dailySeed(new Date())          // e.g. 20260901
const grid = generateGrid(5, 'numbers', seed)
console.log(grid.map((c) => c.value).join(','))
// 17,14,11,9,16,4,10,21,20,6,13,2,18,24,8,25,22,7,5,15,3,1,12,23,19
```

Works in browsers and Node 18+, zero dependencies, ES modules.

### Challenge links (zero backend)

A "beat my time" link packs the entire board state into the URL: `{v:1, seed, size, mode, content, t}` (t = challenger's milliseconds), base64url-encoded. The friend decodes it, plays the identical seeded grid, and the page compares times. `encodeChallenge` / `decodeChallenge` included.

## 中文

**[SchulteLab 每日挑战](https://schultelab.org/zh/daily-challenge/)背后的种子算法**——一个 UTC 日期 → 一张确定的舒尔特方格，全球玩家拿到的完全相同。

**为什么开源**：每日挑战宣称"全球同版"。这句话不该靠信任我们，而该靠**可运行验证**。本仓库与网站生产代码（`challenge.ts` + `engine.ts`）逐字节一致，测试向量由生产引擎生成。如果这里的输出和网站不一致，那是网站的错——这正是开源的意义。

### 算法（三步）

1. **日期 → 种子**（整数）：`seed = 年×10000 + 月×100 + 日`（UTC），如 `2026-09-01 → 20260901`
2. **种子 → 随机源**：mulberry32（微型确定性 32 位伪随机数发生器）
3. **随机源 → 牌面**：生成有序目标序列（数字 `1…N²`，字母 `A–Z`），用该随机源做 Fisher–Yates 洗牌

同一天 → 同种子 → 同洗牌 → 同一张牌。无服务器、无数据库、无时区漂移（统一 UTC）。
